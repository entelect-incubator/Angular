# Phase 8 Tasks

Start from [`src/01. StartProject`](./src/01.%20StartProject/) and compare with `src/02. EndProject`.

1. Verify the supported identity provider and API authorization contract.
2. Configure the chosen OIDC/OAuth integration without embedding secrets.
3. Add UI role-aware controls and navigation behavior.
4. Test unauthenticated, insufficient-role, and authenticated flows.
5. Document which checks are enforced by the backend; do not rely on guards for security.
