# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Primary users are developers learning Angular from the fundamentals. They need a guided, hands-on path that lets them practice concepts in a real application context.

## Product Purpose
The Angular Incubator teaches modern Angular progressively by having learners evolve Pezza Pizza Store from a local pizza catalogue into a complete customer and restaurant application. Success means learners can explain and validate the Angular concepts they use, not merely copy a finished solution.

## Positioning
One evolving Pezza application connects each learning phase; start projects provide exercises and end projects provide working references, following the Entelect .NET Incubator's practical progression.

## Operating Context
Learners use the repository's phase guides, Angular projects, tests, and AI development material on their own machines. Phase 1 must run locally without backend services or private credentials.

## Capabilities and Constraints
- Target Angular 22, TypeScript 6, Node.js 24 LTS, standalone components, and strict typing.
- Use signals and zoneless Angular as the modern baseline.
- Build customer and restaurant administration workflows incrementally.
- Integrate existing Pezza and mock-delivery services only after verifying their contracts.
- The main Pezza API's authentication and exact API contract remain to be verified.
- Use Optimus UI as the design system after checking the current supported package/API.
- Frontend route guards improve navigation but do not authorize backend operations.

## Brand Commitments
The learning application is named Pezza Pizza Store and uses the Pezza restaurant context. No visual identity, logo, or palette has been confirmed for this Angular repository.

## Evidence on Hand
- Existing .NET Incubator phases demonstrate start/end projects and detailed learning README files.
- The local Intro documentation identifies Pezza API and database container images.
- The local Pezzza Mock Delivery Service repository includes an OpenAPI contract and service documentation.
- No Optimus UI components have yet been integrated into the Angular project.

## Product Principles
- Teach by building and explaining, not by copying disconnected examples.
- Keep each phase small enough to complete and validate independently.
- Prefer Angular's built-in capabilities before introducing additional state libraries.
- Verify API, package, and design-system contracts instead of guessing.

## Accessibility & Inclusion
Use semantic HTML, keyboard-accessible interactions, visible focus, and accessible form feedback throughout the learning application.
