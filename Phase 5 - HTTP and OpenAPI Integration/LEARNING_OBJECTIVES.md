# Phase 5 Learning Objectives

- Configure Angular `HttpClient` and centralized request/error behavior.
- Inspect the real Pezza and delivery OpenAPI contracts before generating clients.
- Generate the delivery client from the Pezzza Mock Delivery Service contract.
- Distinguish the .NET delivery service runtime from the generated TypeScript client.
- Generate and consume typed `typescript-angular` clients.
- Keep generated DTOs and HTTP concerns out of UI components.
- Present loading, empty, retry, and error states clearly.
