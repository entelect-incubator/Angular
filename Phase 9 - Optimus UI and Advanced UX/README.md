# Pezza - Phase 9: Optimus UI and Advanced UX

Requires Node.js 24 LTS and npm. **Estimated time:** 4–6 hours — **Difficulty:** ★★★★☆  
**Prerequisites:** Phase 8 or equivalent accessible and authenticated application experience.

## Goal

Apply the [Optimus UI](https://optimus.openng.org/) design system and Tailwind CSS to create a consistent, accessible customer storefront and restaurant admin portal.

## Learning outcomes

- Inspect Optimus UI's current installation, components, theming, and peer requirements.
- Reuse components and tokens instead of inventing a parallel design system.
- Apply responsive, mobile-first layouts and clear visual hierarchy.
- Improve keyboard, focus, labeling, and assistive-technology behavior.
- Design loading, empty, error, and success states consistently.
- Use animation only when it supports user understanding.

## Start and end projects

- **Start:** [`src/01. StartProject`](./src/01.%20StartProject/) — functional Pezza app with foundational styles.
- **End:** [`src/02. EndProject`](./src/02.%20EndProject/) — polished, responsive storefront and admin UX.

## Tasks and acceptance criteria

Verify package APIs/peer compatibility from the official Optimus docs and package before installation. Apply shared tokens and selected components, preserve semantic markup, and test key responsive and keyboard paths. Do not invent component names or APIs.
