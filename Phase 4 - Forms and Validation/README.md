# Pezza - Phase 4: Forms and Validation

Requires Node.js 24 LTS and npm. **Estimated time:** 4–6 hours — **Difficulty:** ★★★☆☆  
**Prerequisites:** Phase 3 or equivalent routing and component experience.

## Goal

Let customers customize a pizza and submit delivery details through a validated checkout journey.

## Learning outcomes

- Manage form state and validation using Angular Signal Forms.
- Represent typed form data and reusable field feedback.
- Handle custom and server validation errors accessibly.
- Validate external data at its boundary without duplicating every form rule.
- Preserve form state intentionally as users navigate.

## Start and end projects

- **Start:** [`src/01. StartProject`](./src/01.%20StartProject/) — routed Pezza storefront.
- **End:** [`src/02. EndProject`](./src/02.%20EndProject/) — pizza customization and validated checkout.

## Tasks and acceptance criteria

Build a typed checkout form with required customer and delivery details, visible field errors, and a review/submit state. Invalid data cannot be submitted, errors are associated with fields, and the build/tests pass.
