# Pezza - Phase 12: AI-Assisted Angular Development

Requires Node.js 24 LTS, npm, and an AI coding assistant. **Estimated time:** 3–5 hours — **Difficulty:** ★★★★☆  
**Prerequisites:** Phase 11 or equivalent familiarity with the complete application and its quality gates.

## Goal

Use AI agents to accelerate Angular development while preserving learning, architectural judgment, privacy, and review discipline.

## Learning outcomes

- Supply project architecture and phase context to an agent.
- Write bounded prompts for implementation, tests, and review.
- Use official Angular documentation context and tools responsibly.
- Evaluate generated code for API accuracy, accessibility, security, and tests.
- Explain, validate, and own any accepted AI-generated change.

## Start and end projects

- **Start:** [`src/01. StartProject`](./src/01.%20StartProject/) — completed Pezza app with basic AI guidance.
- **End:** [`src/02. EndProject`](./src/02.%20EndProject/) — documented, reviewable AI-assisted workflow and examples.

## Tasks and acceptance criteria

Use an agent to implement a bounded app change, ask it to explain the implementation, and conduct a separate review against project conventions. Record the prompt, human review findings, and checks performed. Do not accept changes that cannot be explained or verified.
