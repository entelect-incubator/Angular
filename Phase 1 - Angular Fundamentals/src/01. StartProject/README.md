# Phase 1 Start Project

This is the intentionally small exercise project. It contains the Angular 22 standalone application shell and routing setup. Complete the catalogue tasks in the [Phase 1 guide](../../README.md); compare with `../02. EndProject` after your attempt.

From the repository root, use `npm ci` once, then `npm start` to run this project. The root `npm run ci` command builds and tests all registered projects and runs Oxlint.

The start project uses the Angular CLI's Vitest configuration and requires no API or Docker services.
