# Phase 1 End Project

This is the completed Phase 1 reference: a responsive Pezza pizza catalogue backed by local sample data, with a reusable card component and component tests.

From the repository root, use `npm ci` once, then `npm run start:end` to run this project. The root `npm run ci` command builds and tests all registered projects and runs Oxlint.

The project intentionally does not introduce a backend, basket state, Tailwind, or Optimus UI; those concerns arrive in later phases.
