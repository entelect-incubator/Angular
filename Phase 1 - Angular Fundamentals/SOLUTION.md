# Phase 1 Solution

The reference implementation is [`src/02. EndProject`](./src/02.%20EndProject/).

It uses a typed `Pizza` model and `PizzaCatalogService`, a standalone pizza-card component with required input and typed output, and a responsive catalogue template. The add action displays a status message; basket state is left for Phase 2.

Run `npm install`, `npm start`, `npm run build`, and `npm test` from the end-project directory. No API or Docker service is needed.
