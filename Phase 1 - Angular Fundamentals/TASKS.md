# Phase 1 Tasks

Work in [`src/01. StartProject`](./src/01.%20StartProject/) and use the [`README.md`](./README.md) acceptance criteria.

1. Define a `Pizza` interface with a stable identifier, name, description, ingredients, and price.
2. Create an injectable catalogue service that returns typed local sample data.
3. Create a standalone pizza card with a required pizza input and a typed add output.
4. Render cards in the root catalogue with `@for`; show an empty state with `@if`.
5. Handle the add event and show an accessible confirmation.
6. Add tests for the rendered catalogue and add action.
7. Run `npm run build` and `npm test`.

The completed example is in [`src/02. EndProject`](./src/02.%20EndProject/).
