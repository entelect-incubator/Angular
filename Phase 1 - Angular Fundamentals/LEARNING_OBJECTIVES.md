# Phase 1 Learning Objectives

By the end of this phase, learners should be able to:

- Explain the Angular CLI app entry points and the role of a standalone root component.
- Define and use a strict TypeScript interface for pizza catalogue data.
- Inject a focused service into a component.
- Pass data into a reusable component and emit a typed user action.
- Render repeated and conditional content with Angular template control flow.
- Keep Angular template, TypeScript, and stylesheet in separate files.
- Add a behavior-oriented component test and run the project's build/test scripts.
